# Contributing

Thanks for contributing to **owner-username/.github**.

## Setup

```bash
git clone https://github.com/owner-username/.github.git
cd .github
```

## Pull requests

1. Branch from `main`.
2. Keep the org profile concise — link out to template repos for detail.
3. Open a PR using the repository template.

If your org also uses `.github-private`, sync member-only catalog changes there separately.
