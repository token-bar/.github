# .github

Organization meta-repository for [**token-bar**](https://github.com/token-bar) — governance, automation, and the public org profile for **TokenBar**.

**TokenBar** is a native macOS menu bar app that unifies AI usage across Cursor, OpenAI, Anthropic, and more — track tokens, credits, spend, and burn rate in one place.

## Organization profile

The visitor-facing page at [github.com/token-bar](https://github.com/token-bar) is rendered from [`profile/README.md`](profile/README.md).

## Repositories

| Repository | Summary |
|------------|---------|
| [**.github**](https://github.com/token-bar/.github) | Public organization meta-repository (profile, governance, and automation) |

The TokenBar application is developed in a **private** repository. The public org page is [github.com/token-bar](https://github.com/token-bar).
